Put ffmpeg.exe here (this folder) to get real video recording.

1. Go to https://www.gyan.dev/ffmpeg/builds/  and download "ffmpeg-release-essentials.zip"
2. Unzip. Inside the "bin" folder there is ffmpeg.exe
3. Copy ffmpeg.exe into this "tools" folder, next to this README

Nothing to configure. habitat_notes finds it on start and prints
"habitat_notes: ffmpeg found" in the Output panel.
