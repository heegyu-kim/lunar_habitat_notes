작성 2026-11-04 (2판). 3주 디벨롭 중 1번 과제의 브리프.

---

## 0. 한 줄 요약

이 거주지는 **우리 VR 디자인 리뷰 도구의 기본 예제 공간**이다. NASA 자료를 해석해 만든 가안이고, 목적은 두 가지다. (1) 도구의 사용성을 점검하고 시연한다. (2) 다른 디자이너·엔지니어가 **자기 3D 모델을 가져와도 같은 기능**(구역 설정, 소음 설정, 자동 미니맵, 구역별 노트 집계)을 얻는다는 걸 증명한다. 그래서 산출물은 둘이다.

- **A. 공간 설정 파이프라인** (도구 기능): 모델 임포트 → 바닥·층 자동 인식 → 구역 그리기와 성격 지정 → 소음 요소 배치 → 미니맵 자동 생성 → 세션에 저장.
- **B. 기본 거주지** (예제 콘텐츠): NASA Surface Habitat 참조 설계를 코어로 두고 엔지니어링·거주 모듈을 붙인 4인 기지. **반드시 A 파이프라인을 통해** 설정한다. 우리가 손으로 특별 처리한 것이 하나라도 있으면 다른 사람의 모델에서는 안 된다.

원칙: **모델 이름 규칙에 기대지 않는다.** 남의 glb는 우리 이름 규칙을 따르지 않는다. 구역·층·소음은 모두 모델 바깥의 데이터(세션 json)로 저장하고, 모델은 "형상 + 충돌"만 제공한다.

## 1. 사용자 시나리오 (외부 디자이너가 자기 모델을 가져오는 흐름)

1. **가져오기.** Session 탭 → Import model → 자기 `habitat.glb` 선택. 단위(mm/cm/m)와 업축(Y/Z)을 고르면 바닥이 y=0에 맞춰져 나타난다. 노트 부착용 충돌은 자동 생성(기존 `HabitatSurfaceCollision`이 이미 모델 비의존이다).
2. **층 확인.** 도구가 바닥면을 찾아 "층 2개 (0.0 m, 2.8 m)"라고 제안한다. 사용자는 층을 추가·삭제하거나 이름을 바꾼다.
3. **구역 그리기.** 미니맵(또는 바닥)에 사각형을 드래그해 "Crew quarters A"를 만들고 유형 프리셋 "침실"을 고른다. 성격(조용/깨끗/사적)과 허용 소음 35 dB가 자동으로 채워진다. 필요하면 바꾼다.
4. **소음 요소 배치.** ECLSS 팬을 놓고 "팬, 65 dB @ 1 m"를 고른다. 미니맵의 침실이 붉어지며 "예상 48 dB > 허용 35 dB" 경고가 뜬다. 사용자는 벽을 옮기거나 팬을 옮기거나, 그 자리에 Constraint 노트를 붙인다.
5. **리뷰.** 팀원이 VR로 들어온다. 손목 보드 Map 탭에서 자기 위치와 구역별 노트 수를 보고, 탭 한 번으로 그 구역으로 텔레포트한다.
6. **저장·공유.** 세션 json 하나에 모델 참조, 층, 구역, 소음원, 노트가 모두 들어 있다. 모델 파일과 함께 보내면 상대도 같은 상태를 연다.
7. **리포트.** HTML 리포트가 구역별로 노트를 묶고, 소음 초과 구역을 맨 위에 적는다.

기본 거주지는 이 7단계를 **처음부터 끝까지** 통과한 세션 파일로 배포한다. 앱이 처음 켜지면 그 세션이 로드된다.

## 2. 파이프라인 기능 명세

### 2.1 모델 임포트

| 항목 | 결정 |
|---|---|
| 포맷 | glb/gltf 우선(Godot `GLTFDocument` 런타임 로드). obj는 2차 |
| 위치 | `user://sticky_notes/models/<파일명>` 으로 복사. 세션 json은 파일명만 저장 |
| 입력 UI | 데스크톱: Session 탭 Import model → FileDialog. VR: 같은 탭에서 models 폴더의 파일 목록 중 선택(파일 다이얼로그는 VR에서 못 쓴다) |
| 보정 | 스케일 프리셋(0.001 / 0.01 / 1), 업축(Y/Z), "바닥을 0에 맞춤"(AABB 최저점 → y=0), 중심 맞춤(AABB 중심 xz → 0) |
| 충돌 | 기존 `HabitatSurfaceCollision`을 임포트 노드 아래에 붙여 그대로 생성. `min_size`는 사용자가 조절 가능 |
| 교체 | 새 모델을 가져오면 기존 노트는 남긴다(좌표는 월드 기준). 위치가 모델 밖이면 목록에 "떠 있음" 표시 |
| 저장 | `"model": {"file": "habitat.glb", "scale": 1.0, "up_axis": "Y", "offset": [0,0,0]}` |

### 2.2 바닥·층 자동 인식

입력: 모델의 모든 삼각형. 출력: 층 목록과 층별 바닥 마스크(미니맵 원본).

1. 법선이 위를 향한(normal.y > 0.8) 삼각형만 모은다.
2. 삼각형 중심 높이로 **면적 가중 히스토그램**(간격 0.1 m)을 만든다. 2.0 m 이상 떨어진 봉우리마다 층 후보. 면적이 전체의 3% 미만인 봉우리는 선반·테이블로 보고 버린다.
3. 각 층 높이 ±0.15 m 안의 상향 삼각형을 **0.1 m 그리드로 래스터**해 바닥 마스크(비트맵)를 만든다. 작은 구멍은 메워서(closing 3×3) 통로가 끊기지 않게 한다.
4. 층마다 보이지 않는 `StaticBody3D` 평면을 만들어 `habitat_floor` 그룹에 넣는다. 데스크톱 걷기·사다리가 그대로 동작한다.
5. 사용자 수정: 층 추가(높이 입력), 삭제, 이름. 사다리·계단은 자동 인식하지 않고 **Landing 지점을 사용자가 찍는다**(VR에서 서서 "Set landing" 버튼). `XRLadder.landings`가 이 데이터를 읽도록 바꾼다.

저장: `"floors": [{"id": "f0", "name": "L1", "y": 0.0, "mask_file": "floor_f0.png", "mask_origin": [-8, -8], "mask_cell": 0.1, "landings": [[0,0,0]]}]`

### 2.3 구역 그리기와 성격 지정

| 그리기 | 데스크톱: 미니맵에서 드래그. VR: 바닥을 트리거로 두 모서리 찍기. 수정: 모서리 끌기 |

### 2.4 소음 요소

| 항목 | 결정 |
|---|---|
| 배치 | 노트처럼 표면에 붙이거나 바닥에 놓는 작은 스피커 아이콘. 트리거로 배치, 탭으로 편집 |
| 속성 | 이름, 유형 프리셋(팬 60, 펌프 65, 압축기 75, 운동기구 70, 대화 60, 공방 공구 80 dB @ 1 m), 수치 직접 입력 가능, 가동 시간(상시/주간/간헐) |
| 전파 모델 | 1차는 단순 규칙. 거리 감쇠 20·log10(r), 구역 경계 하나 넘을 때마다 −15 dB(격벽), 같은 구역 안은 감쇠 없음, 층이 다르면 −25 dB. 구역 예상 소음 = 모든 소스의 dB 합(에너지 합산). 물리적으로 정확하지 않다는 걸 UI에 적는다 |
| 표시 | 미니맵 히트맵(소스 주변 그라데이션), 구역이 허용치를 넘으면 구역 색면이 붉은 빗금, 목록 제목줄에 "Noise: Crew quarters A 48 > 35" |
| 노트와의 관계 | 자동으로 노트를 만들지 않는다(도구가 판단을 대신하지 않는다). 경고 옆 "Note here" 버튼으로 사용자가 Constraint를 붙인다. 기존 충돌 펄스와 같은 급의 공간 신호 |
| 가청화(선택) | 2차: 소스에 실제 루프 오디오를 달아 VR에서 거리에 따라 들리게. 침실에 서서 "팬 소리가 들린다"를 몸으로 확인 |

저장: `"noise_sources": [{"id": "n1", "name": "ARS fan", "preset": "fan", "db_at_1m": 65, "position": [..], "duty": "always"}]`

### 2.5 미니맵 자동 생성 (3번 팀과의 계약)

입력은 2.2~2.4의 데이터뿐이다. 모델 이름은 쓰지 않는다.

- 바탕: 층별 바닥 마스크(png)를 밝은 회색으로. 모델 외곽은 마스크에서 나온다.
- 겹: 구역 색면(유형 색, 30% 알파) → 소음 히트맵 → 노트 핀(유형 색 점, 구역별 수 배지) → 내 위치(화살표) → Landing 점.
- 조작: 층 탭, 확대(손목 보드에서 크게 띄우기), 구역 탭 → 그 구역의 Landing(없으면 구역 중심의 바닥 점)으로 텔레포트, 핀 탭 → 노트 열기.
- 갱신: 구역·소음·노트가 바뀔 때만 다시 그린다(초당 재생성 금지).

### 2.6 세션 파일 (version 2)

```json
{
  "format": "sticky_notes",
  "version": 2,
  "model": { "file": "base_camp.glb", "scale": 1.0, "up_axis": "Y", "offset": [0, 0, 0] },
  "floors": [ ... 2.2 ... ],
  "zones": [ ... 2.3 ... ],
  "noise_sources": [ ... 2.4 ... ],
  "notes": [ { "...기존 필드...", "zone_id": "z3" } ]
}
```

version 1 파일은 그대로 열린다(model·floors·zones 없음 → 현재 씬 기본값 사용). 리포트는 구역별 섹션과 "소음 초과" 요약을 맨 위에 추가한다.

## 3. 기본 거주지 (예제 콘텐츠)

### 3.1 근거 (요약)

- 현재 glb는 NASA **Artemis Surface Habitat 참조 설계**(Burke, Howard, Kessler, ASCEND 2022)를 그대로 옮긴 것이다. 2인 30일, 1층 금속(직경 4.4 m) + 2~3층 인플레이터블(외경 6.5 m, 코어 3.3 m), 거주 체적 127 m³, Collins ECLSS 팔레트 10개, 수트포트 에어락. 노드 이름이 논문 구성과 일치한다.
- 논문이 스스로 지적한 결함: 침실 두 개가 벽을 공유해 소음 차단이 안 됨, 수트포트가 정비 구역으로 바로 열림, 팔레트가 끼어 정비 불가, 침실 하나는 의무실을 지나야 함, 4인 수용 불가. 해법으로 다중 모듈 도킹 제시.
- 기능별 최소 면적(NASA 참조 연구, 높이 2.4 m): 취침 1.82, 스트레칭 1.40, 운동 1.50, 위생 1.06, UWMS 0.91, 워드룸 1.62, 의료 1.87, 작업대 1.37, 통로 폭 1.0 m, 에어락 5.0 m²(높이 2.6).
- 구역 분리 원칙: ISS 거주모듈(1988)은 음향 기준 3구역(조용 침실 / 수납·위생 완충 / 작업). Gateway I-HAB는 50 m³에서도 작업·거주 분리를 요구. 먼지는 에어락이 1차 방어선. 태양 폭풍 4일 대비 물탱크·대형 장비를 외벽에.
- 원자로(FSP, 40 kWe, 6 t 이하): 거리 자체가 차폐. NASA 전개형 연구는 약 1 km 이격, 고전압 케이블. 대안은 레골리스 매립.
- SOM·ESA·MIT Moon Village: 인플레이터블 군집 + 레골리스 외피, 섀클턴 크레이터 림.

### 3.2 왜 이 구성이 좋은 "예제"인가

- **프리셋 15종이 전부 한 번 이상 등장**해 구역 설정 UI를 모두 시연한다.
- **의도적 결함을 하나 남긴다.** 코어 타워 3층의 침실 둘은 NASA 논문 그대로 벽을 공유하고 ARS 팔레트 옆이다. 기본 세션을 열면 도구가 "Crew quarters (core) 52 dB > 35"를 띄운다. 리뷰 도구가 실제 NASA 설계 문제를 잡아내는 장면이 데모의 첫 30초다.
- **다층 + 다모듈**이라 미니맵의 층 전환과 모듈 간 텔레포트가 필요해진다.
- 먼지 동선(에어락→수트실→복도→거주)이 길어서 구역 "청결" 축이 의미를 가진다.
- 창 2개와 외부 환경이 있어 Inhabitant 역할의 노트("창이 지구를 향하는가")가 나온다.

### 3.3 구성

| 모듈 | 형태 | 내용 |

## 4. Godot 시각 품질

PC + Quest Link 제출로 확정됐으므로 데스크톱 GPU 기준.

- **Forward+ 전환.** SSAO, SSIL, 볼류메트릭 포그, SDFGI가 열린다. 전환 후 노트 투명 재질(render_priority)이 그대로인지 먼저 확인. 목표 72 Hz.
- **기본 씬**: LightmapGI 베이크(interior, bounces 3), 실별 ReflectionProbe, SSAO. 동적 노트·컨트롤러는 라이트맵 프로브로 받는다.
- **임포트된 모델**: 베이크 불가(런타임 로드). SDFGI + SSAO + 실시간 광원으로 간다. 구역에 색온도가 지정되면 그 구역 안의 광원을 자동 틴트(2.3의 `color_temp_k`). 이게 "공간별 성격을 선택하면 조명이 따라온다"의 구현이다.
- **외부**: 태양 DirectionalLight 고도 2°, 그림자 캐스케이드 4, 거리 300 m. 지구광 약한 푸른 보조광. 하늘은 검정 + 별 + 지구 빌보드. 레골리스 albedo 0.08~0.12.
- **구역별 조명 성격**: 엔지니어링 4500~5000 K 평평한 천장 라인 + 팔레트 상태등, 거주 2700~3200 K 간접 코브 + 창 빛, 코어 4000 K.
- 재질: PBR, 트림 시트 1장으로 패널·리벳·라벨 통일, 유리는 스페큘러만. 텍스처 실내 2 K, 지형 4 K.
- 예산: 드로우콜 1,500, 삼각형 300만, VRAM 2 GB.

## 6. 1주 일정 (11/4 ~ 11/10)

파이프라인을 먼저 만들고, 기본 거주지를 그 파이프라인으로 설정한다.

진행 상황 (11/6): **1~7일차 구현 완료, 통합 테스트 통과.**

- 1일차 임포트: `space/space_model.gd`, 세션 v2, Session 탭 UI, 마지막 세션·모델 기억.
- 2일차 층: `space/space_floors.gd`(상향 삼각형 히스토그램 + 헤드룸 규칙으로 지붕 제외, 0.1 m 마스크, 층별 충돌체). 기본 거주지 3층(−0.02 / 2.58 / 5.20), 상자 집 테스트 2층. 랜딩 편집, 사다리 A/X·Space/C 가 가져온 모델에서도 층 이동.
- 3일차 구역: `space/space_presets.gd` 16종 프리셋, 두 모서리 입력, `zone_visuals.gd` 발광 외곽선·이름, 노트 `zone_id`, 목록 구역 필터, 리포트 구역 요약.
- 4일차 소음: 프리셋 이미터, 단순 전파 규칙, 구역 초과 경고(씬 빨간 외곽선·목록·리포트). 허용치는 "그 방의 장비까지 포함해 견디는 수준"으로 잡았다(공방 85, 운동 75, 침실 35).
- 5일차 기본 거주지: `tools/build_base_camp.tscn`이 CSG로 B·C·D·터널·외부 시설을 `assets/models/Base_Camp/*.glb` 두 파일로 생성(외부 시설은 층 인식에 끼지 않도록 별도 glb, 씬 루트에). 외부 환경 `scripts/lunar_exterior.gd`(별하늘 셰이더·지구·태양 2°·레골리스 지형·지구광).
- 6일차 시각: Forward+ 전환, SSAO, `scripts/habitat_lights.gd`가 실별 조명을 두고 구역 색온도를 적용. 라이트맵 베이크는 에디터에서만 가능하므로 미실시.
- 7일차 기본 세션: `tools/build_default_session.tscn` → `assets/sessions/default_base_camp.json` (구역 33, 소음원 17). 첫 실행 시 자동 로드되고 코어 침실 2개가 40 > 35 dB 로 경고.

(11/6 저녁) 품질 판단에 따라 **CSG blockout 과 코드 조명은 씬에서 뺐다.** 기본 씬은 NASA 참조 타워 + 외부 환경(하늘·지형·태양)만이고, 기본 세션도 타워의 방 10개와 소음원 5개로 줄였다. blockout glb 와 생성기는 배치 참고용으로 저장소에 남긴다. 디테일 모델링·재질·조명은 Blender 에서 만들어 `LunarHabitat` 아래에 넣는다(README "Putting your own habitat model in as the default"). 파이프라인(층·구역·소음·세션)은 그 모델에 그대로 동작한다.

남은 것: Blender 모델 반입 후 기본 세션 표 갱신, 라이트맵 베이크, 사다리 위치가 여러 개인 모델에 대한 XRLadder 확장, 헤드셋 성능(72 Hz) 확인.

| 일 | 작업 | 체크 |
|---|---|---|
| 1 (수) | 세션 version 2 스키마, 모델 임포트(데스크톱 FileDialog, 스케일·업축·바닥 맞춤), 임포트 노드에 충돌 자동 생성 | 인터넷에서 받은 아무 glb 하나가 들어오고 노트가 붙는다 |

| 3 (금) | 구역 그리기(데스크톱 드래그 + VR 두 점), 프리셋 카탈로그, 노트 zone_id, 목록 구역 필터 | 구역 5개 만들고 저장·로드 왕복 |
| 4 (토) | 소음원 배치·편집, 구역 소음 계산, 경고 표시, 리포트 구역 섹션 | 코어 침실이 ARS 때문에 초과로 뜬다 |
| 5 (일) | 기본 거주지 블로킹: B·C·D 외피, 터널, 바닥, 해치 위치, 외부 지형·하늘·태양 | 걸어서 동선 4개 통과. 창밖이 달 |

위험과 대비:

- 런타임 glb 로드가 머티리얼·텍스처를 못 가져오는 모델이 있으면 → 임포트 시 경고만 띄우고 회색 재질로 진행.
- 층 인식이 경사로·계단이 많은 모델에서 틀리면 → 사용자가 층 높이를 손으로 입력하는 경로가 항상 있으므로 자동은 "제안"으로 둔다.
- 모델링 일정이 밀리면 → B·C 내부 소품을 줄이고 외피·바닥·해치·창·핵심 장비(팔레트, 침상, 테이블)만 둔다. 파이프라인과 기본 세션이 우선.
- Forward+ 전환으로 노트 재질이 깨지면 → 하루 안에 Mobile로 되돌리고 SSAO·포그만 포기.
